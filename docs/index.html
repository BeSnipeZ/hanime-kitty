Warum man HTV vertrauen kann

  1. Die Menge ist fest: Das Recht zum Nachprägen ist gelöscht, auch für die Gründer.

  3. Der ganze Code ist öffentlich und getestet.

HTV ist ein Spaß-Coin für die Community, keine Geldanlage und kein Gewinnversprechen.
